# Self-Hosting Node-RED

---

# Advantages

- Greater performance
  - Fast to deploy
- Custom nodes
- Development environment
  - Test flows locally before deploying to production

---

# Disadvantages

- Need to configure local tunnel setup to expose local Node-RED server to the internet. (`ERPNext` -> `Node-RED` connection)

---

# Setting up `Node-Red`

---

# Software

- Install [Node.js](https://nodejs.org/en/) (Version 24)
- Install [Visual Studio Code](https://code.visualstudio.com/)

---

# VSCode

- Change default terminal in `VSCode` (Windows only)
  - Open a window
  - Select `terminal` -> `New Terminal`
  - press `ctrl` + `p`
  - Type `> Terminal: Select Default Profile` and click
  - Select `cmd`

---

# Package Manager

- `Node.js` comes with `npm` package manager.
  - But it is quite slow.
- Let's use a more performant package manager call `pnpm`.
  - `npm install -g pnpm`

---

# Installing `Node-Red`

- Create a new folder
- Drag a folder into `VSCode`
- Select `terminal` -> `New Terminal`

---

# Installing `Node-Red`

- `pnpm init`
- `pnpm install node-red @flowfuse/node-red-dashboard node-red-contrib-telegrambot node-red-contrib-influxdb`
- `pnpm approve-builds`

---

# Modifying `package.json`

```json
{
  "scripts": {
    "start": "node-red -u ./local -p 1880"
  }
}
```

---

# Accessing `Node-Red`

- Visit the web browser at
  - `http://127.0.0.1:1880` or
  - `http://localhost:1880`
