# What is Local Tunnel?

- A tool to expose your local server to the internet.
- Useful for development and testing.
- Creates a secure tunnel from a public URL to your local machine.
- Examples: `ngrok`, `localtunnel`, `serveo`, `LocalXpose`
- In this lecture, we will use `LocalXpose`.

---

# Get Started with `LocalXpose`

- Install Node.js (if not already installed)
- Go to [LocalXpose website](https://localxpose.io/)
- Sign up for an account
- [Install](https://localxpose.io/dashboard/access) `LocalXpose` CLI
  - Follow the login instructions to authenticate your CLI.

---

# Start a Tunnel with `LocalXpose`

- `loclx tunnel http --to localhost:1880`
